# Vice City Reel Queue

A queue page for reposting Instagram reels: copy the link, download it, post it, mark it posted.

- Live page: https://claude.ai/artifact/WuE1rimT2yaTipLipAyZQv (the status of each reel is saved on the page itself, so it syncs between devices)
- `index.html` is the page source.

To add a batch, paste Muse's message into "Add more reels" on the page, or send it to Claude.
